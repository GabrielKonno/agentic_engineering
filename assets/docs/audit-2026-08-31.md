## Correction to the audit's own D12 characterization

Agent 5 reported that 10 files "use `## When to invoke` instead of the canonical
`When this agent is invoked`", implying one section with inconsistent naming. That is wrong, and
acting on it literally would have merged two distinct sections into a duplicate heading — the
maintenance session's assertion caught it before any file was written.

`## When spawned` is the activation-chain section required by component-design §1 (which reviewer
gap routes here, what context the prompt carries, what main Claude does with each outcome).
`## When this agent is invoked` is the TRIGGER section (which diffs warrant the agent). Ten agents
legitimately carry both. Only the trigger heading had a real naming split (8 vs 3), and
`examples/README.md` never documented that the two sections are different — which is what made the
conflation available in the first place. That documentation gap is now closed.

**Lesson for future audits:** a finding phrased as "X should be renamed to Y" deserves a structural
read of the file before it is applied. Two headings that look like paraphrases of each other may be
carrying different contracts.
